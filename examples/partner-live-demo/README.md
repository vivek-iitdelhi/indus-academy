# Acme Learning (partner demo)

Tiny client platform that embeds Indus AI Academy live classes. Node 20+, no dependencies.

    PARTNER_API_KEY=iaa_live_... INDUS_API=http://localhost:3000/api/v1 node server.mjs

Open http://localhost:4000, pick a learner, then Join an open class. The API key stays on the server.
